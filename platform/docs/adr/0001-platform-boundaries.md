# ADR-0001: Платформа не владеет игровым состоянием

- Статус: принято
- Дата: 2026-10-03

## Решение

CreateCityExpansionCore и Minecraft server остаются единственным источником
истины для игрового мира. CreateServerPlatform хранит только внешние аккаунты,
дистрибутивы, аудит и восстанавливаемые проекции.

Telegram bot и launcher работают исключительно через backend. Backend не пишет
в файлы мира и не подключается к внутренней базе SavedData. Интеграция идёт
через узкий версионированный bridge с server-side authorization.

## Причины

- сохраняется принцип server authority;
- physical delivery и Create pipeline нельзя подтвердить внешним сервисом;
- рестарт и временная недоступность платформы не ломают игровой цикл;
- одну и ту же доменную формулу не приходится поддерживать в двух проектах.

## Последствия

Для внешнего UI нужны snapshots/events и состояния `unavailable/stale`. Новые
удалённые мутации требуют отдельного решения, threat model и runtime-проверки.
