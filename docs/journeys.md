# Метки, задачи и путь новичка

Журнал открывается клавишей **F8** (переназначается в управлении) или `/ccec quests`.
В нём три раздела: задачи, пути и места. Нажатие на название задачи открывает
полное описание и условия выполнения; на метку карты — карточку места.
Одновременно закрепляются до трёх задач; навигация ведёт к одной выбранной цели.
«Отложить путь» сохраняет прогресс и приостанавливает проверки и навигацию;
«Продолжить путь» возобновляет их. Отдельные задачи также можно снять с закрепления.

Метки видны на большой карте, миникарте и рядом с игроком в мире. Цель пульсирует,
настроенный маршрут показан спокойной тонкой линией на карте и редкими указателями в мире, завершение шага сопровождается
карточкой и тихим звуком. Учитываются уменьшение движения карты и соответствующая
настройка сообщества. При скрытом интерфейсе эффекты не рисуются; в опасности
карточка навигации скрывается. Геометрия в мире проверяет глубину и не загружает
чанки. Одновременно отображается не больше восьми ближайших меток мира.
Перекрывающиеся точки карты объединяются в счётчик; все доступны в разделе «Места».

## Редактор «Атлас + Экспедиция»

Для цельного пути откройте **Карта → Метки → Редактор пути**. Добавьте шаги
«Дойти до места», «Нажать на блок», «Открыть пилон» или «Собрать предметы».
У каждого шага задайте короткое действие и, при необходимости, подсказку.
Точку взаимодействия можно указать прицелом в мире. Точный блок фиксируется
по Enter. Повороты и радиус находятся в дополнительных настройках.

**Пройти** запускает проверку от начала или выбранного шага, включая
несохранённые правки. Если указали старт, встаньте рядом с ним для полного
прохода. Дойдите до метки, примените клавишу взаимодействия к выбранному блоку
или нажмите Enter рядом с целью для имитации получения предметов. Журнал (F8
по умолчанию) показывает подсказку шага. Esc возвращает в тот же черновик.
Реальный прогресс задач приостановлен до выхода из проверки. Это проход по
текущему миру, поэтому фактическую выдачу предмета и открытие меню стоит
проверить на опубликованном тестовом маршруте в отдельном мире.

**Сохранить** записывает черновик. **Проверить** проверяет условия и цели.
**Опубликовать** делает маршрут доступным из раздела путей в журнале, где
игрок сам его запускает. Публикация заменяет предыдущий опубликованный маршрут.

### Отдельные метки и задачи

На полноэкранной карте нажмите **Метки** или выберите значок. Карта остаётся
в центре: слева — поиск и список, справа — карточка. При узком интерфейсе
список открывается кнопкой **Список**. Для оператора (уровень 2) доступна
кнопка **Редактировать**. Обычный игрок может читать карточки и отслеживать цели.

- **Создать** создаёт локальный черновик выбранного типа: метка, задание или маршрут.
- **Основное**: название, многострочное описание, тип и положение. Место задаётся
  кликом на карте, текущей позицией игрока или координатами. Карта не угадывает высоту:
  проверьте Y перед публикацией.
- **Вид**: восемь пиктограмм, палитра с латунью, размер 8–16, дальность 16–160 блоков,
  отдельные переключатели для карты и мира.
- **Действие**: переход к связанным заданиям и создание задания у выбранной метки.
- **Доступ**: публикация, только новички и открытие после завершения задания.
- **Путь**: клики добавляют до 64 промежуточных точек. Последнюю можно отменить;
  каждая точка открывает редактор X/Y/Z. Это авторский маршрут, не поиск пути по блокам.
- В разделе **Задания** выбираются условия: посещение, взаимодействие с блоком,
  предмет (поиск по названию), город, доставленные грузы, выполненные проекты,
  достижение. Идентификатор достижения вводится явно и проверяется сервером.
- В разделе **Маршруты → Шаги** карточки перетаскиваются или перемещаются кнопками
  «Выше / Ниже». На карте отображается последовательность мест. Для действующего
  маршрута сначала снимите публикацию и сохраните, затем меняйте порядок.

**Сохранить / Ctrl+S** записывает только выбранную запись. Черновики остальных
записей остаются в окне. **Отменить** возвращает выбранную запись к загруженному
состоянию. Закрытие с изменениями требует подтверждения. **Ещё** позволяет
дублировать метку или удалить запись; удаление используемых записей отклоняется.
Новые записи публикуются только после включения «Опубликовано» и сохранения.

Предпросмотр показывает карту для нового игрока без завершённых заданий:
скрытые и закрытые условиями метки не показываются. Личный прогресс не изменяется.
Он не имитирует выполнение цепочки и не телепортирует игрока.

Редактор работает с отдельными копиями данных, проверяет права на каждом запросе,
ограничивает частоту и размер сообщений. Каждый ответ каталога содержит только
одну запись, без прогресса игроков. Если запись изменена другим автором или командой,
сохранение отклоняется; можно скопировать черновик и заново открыть редактор.
Изменённое условие получает новый ID, поэтому старое подтверждение его не завершает.
Уже завершённое задание остаётся завершённым — для новой кампании создайте новое.

Оформление: графит, светлый текст, латунные акценты, векторные пиктограммы.
Постоянно анимируется только активная цель; появление и завершение дают краткий
импульс. В режиме уменьшенного движения парение, импульсы и переходы отключены.
Метки в мире проверяют глубину; подписи появляются рядом с целью или при взгляде.

## Настройка оператором

Создание и изменение требуют уровня разрешений **2**. Все изменения сразу
сохраняются в SavedData `ccec_journeys` основного мира и отправляются игрокам.
ID: строчные латинские буквы, цифры, `_`, `-`, `/`, `.`; длина до 64 символов.
Новые задачи и цепочки создаются выключенными, чтобы промежуточная настройка
не запускала обучение. Метка, созданная командой, сразу включена; метка из редактора создаётся неопубликованной.

```mcfunction
/ccec marker create reception here
/ccec marker set reception title Добро пожаловать
/ccec marker set reception description Здесь начинается знакомство с городом. Откройте журнал клавишей F8.
/ccec marker set reception type guide
/ccec marker set reception radius 6
/ccec marker set reception audience newcomers
/ccec marker set reception enabled true
/ccec marker info reception
/ccec marker list
```

Типы: `guide`, `quest`, `activity`, `landmark`. У них разные символы и цвета.
Аудитория: `all` или `newcomers`. Последняя скрывается после завершения
автоматической цепочки; возраст аккаунта и время игры не используются.

Переместить метку: `/ccec marker move reception here` или
`/ccec marker move reception 100 65 -30` (поддерживаются относительные координаты).
Измерение берётся из текущего мира исполнителя команды. Перемещение очищает
старый маршрут, поскольку тот уже может вести в другое место.

## Первая цепочка

На точке знакомства:

```mcfunction
/ccec quest create welcome
/ccec quest set welcome title Познакомьтесь с городом
/ccec quest set welcome description Подойдите к точке знакомства. Следующая цель появится после посещения.
/ccec quest set welcome marker reception
/ccec quest objective add welcome visit reception 1
/ccec quest set welcome enabled true
```

У городского пилона создайте следующую точку:

```mcfunction
/ccec marker create pylon_help here
/ccec marker set pylon_help title Городской пилон
/ccec marker set pylon_help description Здесь можно узнать о городе и его территории.
/ccec marker set pylon_help type guide
/ccec marker set pylon_help audience newcomers
/ccec quest create find_pylon
/ccec quest set find_pylon title Найдите городской пилон
/ccec quest set find_pylon marker pylon_help
/ccec quest objective add find_pylon visit pylon_help 1
/ccec quest set find_pylon enabled true
```

Аналогично создайте метку `logistics_help` у входа в логистический центр:

```mcfunction
/ccec marker create logistics_help here
/ccec marker set logistics_help title Логистический центр
/ccec marker set logistics_help description Здесь можно познакомиться с отправками грузов. Практическую доставку можно выполнить позже.
/ccec marker set logistics_help type activity
/ccec quest create find_logistics
/ccec quest set find_logistics title Откройте для себя логистику
/ccec quest set find_logistics marker logistics_help
/ccec quest objective add find_logistics visit logistics_help 1
/ccec quest set find_logistics enabled true
/ccec journey create newcomer
/ccec journey set newcomer title Первые шаги в городе
/ccec journey step add newcomer welcome
/ccec journey step add newcomer find_pylon
/ccec journey step add newcomer find_logistics
/ccec journey set newcomer automatic true
/ccec journey set newcomer enabled true
```

После включения цепочка назначается каждому ещё не записанному игроку,
включая существующих игроков сервера. Вход, смерть и перезапуск не сбрасывают её.
Она назначается автоматически один раз. Цепочки без `automatic` запускаются
в разделе «Пути». Одновременно автоматической может быть одна цепочка.
Шаги идут по порядку, каждый квест принадлежит одной цепочке. Отключённый шаг
приостанавливает продвижение; он не пропускается и не засчитывается.

## Безопасный маршрут

Маршрут хранится у **конечной метки**. Пройдите путь от предыдущей точки к ней
и выполните в поворотах/входах/на мостах:

```mcfunction
/ccec route point add pylon_help here
```

Повторяйте по порядку. Конечная точка метки добавляется автоматически.
Очистка: `/ccec route clear pylon_help`.
Для следующего участка создайте точки маршрута у `logistics_help`.
Везде используется текущее измерение; маршрут между измерениями не разрешён.
Y фиксируется в точках — администратор должен пройти по безопасной поверхности.
Клиент выбирает ближайшую точку пути и последовательно продвигается дальше.
За пределами загруженных чанков линия в мире не рисуется; карта и расстояние
остаются доступны. Если цель в другом измерении, HUD сообщает об этом.

Без промежуточных точек показывается **направление**, а не автоматически
найденная дорога. Система не обещает обход стен, рек или гор.

## Условия задач и существующие механики

Все условия задачи должны быть выполнены. Условия фиксируются независимо:
после подтверждения предмет можно убрать, а место — покинуть.

```mcfunction
/ccec quest objective add task_id visit marker_id 1
/ccec quest objective add task_id interact marker_id 1
/ccec quest objective add task_id item minecraft:iron_ingot 8
/ccec quest objective add task_id city_member
/ccec quest objective add task_id shipment_delivered
/ccec quest objective add task_id project_completed
/ccec quest objective add task_id advancement minecraft:story/mine_stone 1
```

- `visit`: сервер проверяет расстояние в 3D, измерение и радиус метки.
- `interact`: серверный ПКМ по **точному блоку** метки в её радиусе. Командой
  `marker move` задайте координаты самого блока, а не воздуха над ним.
  Это подтверждает взаимодействие, но не чтение экрана и не транзакцию.
- `item`: наличие количества предметов в основном инвентаре/панели быстрого
  доступа, без изъятия; это не доказательство изготовления предмета.
- `city_member`: членство игрока в городе через существующий `CityManager`.
- `shipment_delivered`: хотя бы одна физически завершённая доставка со статусом
  `COMPLETED`, созданная этим игроком. Принятый заказ и чужая доставка не подходят.
- `project_completed`: завершённый проект, в котором игрок назначен личным
  исполнителем. Городское исполнение и роль автора сами по себе не подходят.
- `advancement`: серверное завершение указанного достижения Minecraft.

Существующее подтверждённое состояние засчитывается: предыдущая доставка,
завершённый проект или членство подходят. Это условия достижения, а не счётчик
событий «с момента принятия». Проверка раз в секунду, без загрузки чанков.
Клиент не имеет запроса «завершить задачу» или «выдать награду».
Обычные контекстные подсказки `OnboardingClient` независимы от этих подтверждений.

Для изменения условий сначала отключите задачу:

```mcfunction
/ccec quest set task_id enabled false
/ccec quest objective clear task_id
# Добавить новые условия, затем снова включить.
```

У каждого нового условия свой стабильный ID: старое подтверждение не закроет
новое условие. Уже завершённые задачи остаются завершёнными; для новой версии
обучения используйте новый ID задачи. Для тестирования оператор может сбросить
весь прогресс конкретного игрока: `/ccec journey reset PlayerName`.
Перед изменением порядка шагов отключите цепочку; `journey step clear` очищает
её состав. Отключение меток/задач/цепочек доступно через `set … enabled false`.

## Границы этой версии и проверка

Реализованы линейные цепочки, общие серверные метки и личный прогресс.
Денежные/предметные награды, ветвящиеся цепочки, редактор JSON и синхронизация
с FTB Quests в этот модуль не включены. FTB-кампания остаётся самостоятельной;
совпадение названий не создаёт связь прогресса. Серверные метки также не меняют
локальные личные точки карты или объекты существующих проектов.

Лимиты: 128 меток, 128 задач, 16 условий задачи, 16 цепочек по 32 шага,
64 промежуточные точки маршрута, 3 закреплённые задачи. В снимок клиента
включается подробный маршрут только текущей цели. Запросы клиента ограничены
шестью в секунду и всегда относятся к отправившему игроку.

Автоматические проверки: `./gradlew.bat checkJourneys checkOnboarding checkAtlasExperience jar`.
`checkJourneys` включён в стандартный `check` и проверяет прогресс, порядок шагов,
разделение UUID, сохранение, паузу, идемпотентность, структуру команд, кодеки
и размер максимального снимка. Реальная проверка игры нужна отдельно:
карта/миникарта, ПКМ по пилону, достижение точки и переход к следующей,
переподключение, смена измерения, уменьшение движения, масштаб интерфейса
и отсутствие перехвата кликов при измерении/выборе участка.
