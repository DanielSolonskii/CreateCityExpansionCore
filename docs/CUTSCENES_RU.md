# Кат-сцены RE:CREATED

Редактор открывается в игре на Minecraft 1.21.1 с NeoForge. Для редактирования и запуска команд нужны права оператора уровня 2. Для просмотра игрокам нужна версия мода с поддержкой кат-сцен.

## Создание сцены

1. В нужном измерении введите `/ccec cutscene edit arrival`. Если сцены с таким именем ещё нет, откроется черновик.
2. Задайте длину в тиках. 20 тиков равны одной секунде. Выберите время на шкале и нужную дорожку, затем нажмите **+ Ключ**.
3. Новый ключ камеры берёт текущий вид. Чтобы снять другую точку, нажмите **Навести в мире**, переместитесь, направьте камеру и нажмите `F6`. Координаты и углы также можно ввести вручную. Добавьте несколько ключей для пролёта. Интерполяция, заданная в ключе, действует до следующего.
4. Найдите звук по названию или введите его ID, затем настройте громкость и высоту тона. Кнопка **Прослушать** проигрывает выбранный звук. Можно использовать звуки Minecraft, модов и ресурспака, загруженного у зрителей.
5. На текстовой дорожке задайте текст, время показа и цвета текста и плашки. В цвете `#AARRGGBB` первые две цифры задают непрозрачность. Например, `#D9131822` — полупрозрачный тёмный фон, а `#00131822` — прозрачный.
6. Нажмите **Пуск** или пробел для предпросмотра с текущей отметки. `Esc` вернёт в редактор. **Сохранить** (`Ctrl+S`) записывает JSON на сервер, а **JSON** копирует текущий черновик в буфер обмена.

## Показ игрокам

| Команда | Действие |
| --- | --- |
| `/ccec cutscene list` | Список сохранённых сцен |
| `/ccec cutscene edit <id>` | Создать черновик или открыть сохранённую сцену |
| `/ccec cutscene play <id>` | Показать сцену себе |
| `/ccec cutscene play <id> <игроки>` | Показать сцену выбранным игрокам, например `@a` |
| `/ccec cutscene stop [игроки]` | Остановить показ у себя или у выбранных игроков |
| `/ccec cutscene intro set <id>` | Назначить сцену для первого входа новых игроков |
| `/ccec cutscene intro` | Проверить, какая сцена назначена вступлением |
| `/ccec cutscene intro clear` | Отключить автоматический показ вступления |

Во время показа `Esc` возвращает игрока в игру. Показ идёт в измерении сцены. Камера использует чанки, уже полученные клиентом вокруг персонажа. Для вступления снимайте маршрут возле точки появления и проверьте его с той же дальностью прорисовки, что и на сервере.

## JSON

Сцены хранятся в `<папка мира>/ccec/cutscenes/<id>.json`. ID состоит из строчных латинских букв, цифр, дефисов и подчёркиваний и начинается с буквы или цифры. Чтобы перенести сцену, скопируйте файл в эту папку в другом мире. Сервер читает файл при открытии и запуске сцены.

Пример `arrival.json`. Координаты камеры нужно заменить на координаты вашего маршрута.

```json
{
  "version": 1,
  "dimension": "minecraft:overworld",
  "durationTicks": 140,
  "camera": [
    {"tick": 0, "x": 8.5, "y": 84.0, "z": 18.5, "yaw": -35.0, "pitch": 14.0, "easing": "smooth"},
    {"tick": 140, "x": 30.5, "y": 74.0, "z": 45.5, "yaw": -25.0, "pitch": 5.0, "easing": "linear"}
  ],
  "sounds": [
    {"tick": 12, "sound": "minecraft:block.note_block.chime", "volume": 0.7, "pitch": 1.0}
  ],
  "texts": [
    {"tick": 24, "durationTicks": 82, "text": "Добро пожаловать в RE:CREATED", "textColor": "#FFF5EBDC", "backgroundColor": "#D9131822"}
  ]
}
```

Режимы движения камеры — `linear` (равномерно), `smooth` (плавный разгон и торможение), `ease_in` (разгон), `ease_out` (торможение) и `hold` (удержать кадр до следующей точки). Для сцены с одним звуком или текстом оставьте `camera` пустым массивом. Длина сцены ограничена 12 000 тиков, каждая дорожка — 128 ключами, файл — 128 КиБ в UTF-8.
