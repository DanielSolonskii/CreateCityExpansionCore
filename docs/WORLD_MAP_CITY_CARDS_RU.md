# Карточки городов и редактор герба

Откройте WorldMap клавишей карты и выберите город на карте или через поиск. Справа появятся его название, герб, описание, жители, число участков, измерение и координаты. Город можно найти независимо от расстояния до него. Каталог передаётся страницами по 32 города; число страниц не ограничивает общее число городов.

Карта доступна и игрокам без собственного города. Название измерения в левом верхнем углу карты по клавише переключает доступные измерения. Участки ближайших городов по-прежнему поступают отдельно; публичный каталог добавляет метки и карточки всех остальных городов. Публичная карточка не раскрывает казну, инвентарь, список участников и приватную инфраструктуру.

Владелец и администратор видят действие «Карточка города». Редактор позволяет изменить описание до 400 символов, основной цвет из палитры города и рисунок герба 32×32. Основной цвет меняет также цвет территории; индекс краски 1 следует этому цвету. Индекс 0 прозрачен. Есть кисть, заливка, ПКМ для стирания, зеркальное рисование, отмена и повтор, три переключаемых шаблона: башня, шестерня и промышленность.

Изменения остаются черновиком до нажатия «Сохранить». Первый выход с изменениями предлагает отказаться от черновика; повторное нажатие «Не сохранять» или Escape закрывает редактор. Сервер повторно проверяет права, палитру, текст, рисунок и версию карточки. Если другой администратор уже изменил карточку, сохранение отклоняется: откройте редактор заново, чтобы получить актуальную версию. Ответ сервера связан с конкретным запросом сохранения.

Описание, рисунок и версия сохраняются в CityManager SavedData вместе с городом. У старых городов появляется герб по умолчанию; повреждённый рисунок заменяется шаблоном, сохраняя корректное описание. Публичный каталог обновляется примерно раз в пять секунд в карте по клавише.

Проверка без запуска игры:

```powershell
$env:GRADLE_USER_HOME = Join-Path (Get-Location) '.gradle-user'
.\gradlew.bat checkCityIdentity checkCityTerritory checkCityTerritoryDelivery checkWorldMapPanelLifecycle checkWorldMapUiLayout checkAtlasExperience --offline --no-configuration-cache
```

Проверяются реальные сохранение/загрузка, права, конфликт версий, публичные данные для постороннего игрока, разные измерения, страницы на 1025 городов, сетевой кодек, проекция меток и поиска, редактирование пикселей и восстановление старых сохранений.
