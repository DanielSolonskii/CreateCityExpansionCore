# Дальность и кэш WorldMap

Минимальный масштаб изменён с 0.5 до 0.25: на том же экране можно увидеть вдвое
больше блоков по каждой оси, то есть вчетверо большую площадь.

Рельеф на сервере уже сохранялся в CityMapSavedData. Повторная медленная загрузка
возникала на клиенте: новая панель начинала с пустым кэшем, а закрытие уничтожало
все GPU-текстуры. Теперь данные тайлов общие между открытиями и сохраняются фоновым
потоком в `cache/ccec-atlas` внутри папки Minecraft. Области разделены по серверу,
UUID игрока и измерению; координаты пилона/якоря на ключ не влияют. Для одиночного
мира используется полный путь сохранения, чтобы одинаковые названия миров не
смешивали кэш.

Готовые текстуры передаются в ограниченный пул на закрытии карты. Пул освобождается
при смене области кэша и отключении от сервера. На диске сохраняются только данные
цветов/горизонталей, а не ресурсы GPU. После перезапуска игры файлы читаются
асинхронно, текстуры постепенно строятся из локальных данных без ожидания сети.

Лимит исходных тайлов — 8192 на область, пул текстур — 8192. Дисковые файлы
сжимаются, записываются через временный файл и замену; общий лимит файлов `.atlas`
составляет 256 МиБ (при записи дополнительно существует один временный файл).
Старейшие файлы вытесняются. Повреждённый/несовместимый файл считается отсутствующим.

Первичная загрузка: максимум 8 запросов за 100 мс, в пределах существующего
серверного ограничения 8 запросов за тик. Неизвестные клиенту тайлы приоритетнее
повторной проверки сохранённых; сохранённые проверяются начиная с самых старых,
без очистки готовой подложки. Тайлы старше 30 секунд могут обновляться фоново.
Сервер продолжает присылать изменения отслеживаемых тайлов; число подписок
ограничено 8192 на игрока. Неизменившийся ответ не перестраивает текстуру.

При построении текстуры цвет и покрытие горизонталями теперь вычисляются один раз
на LOD-ячейку. Контрольный расчёт для каждого пикселя на семи уровнях детализации
подтверждает совпадение с прежним алгоритмом. Бюджет перестройки — 16 тайлов за кадр.

Карта использует только уже захваченный сервером рельеф естественно загруженных
чанков. Новые чанки ради дальнего обзора не генерируются и не удерживаются загруженными.

Проверка в игре: повторное открытие того же места, перезапуск клиента, смена
измерения/сервера/игрока, панорамирование и максимальное отдаление, обновление
захваченного рельефа. Скорость и FPS в Minecraft пока не измерялись.
