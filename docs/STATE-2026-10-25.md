- **Backend:** Java 21 / Spring Boot / Gradle; PostgreSQL + JPA + **Flyway V1–V15** (platform infrastructure → identity → accounts+Telegram → alpha keys → phone verification → trusted devices → game sessions → player reports → bridge telemetry → broadcasts → **companion accounts V11 / community relay V12 / launcher profile V13 / experience telemetry V14** → admin publications V15).

- **Infra:** systemd‑юниты (backend, minecraft, telegram‑bot/guard/routing), Caddy, stunnel TLS для game‑auth, старт/стоп Linux‑скрипты, деплой‑скрипты.
