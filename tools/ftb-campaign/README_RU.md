# Кампания FTB Quests

Проверено **02.11.2026**: локальный генератор и verifier проходят на текущих
исходниках. Историческая установка 11.10 описана ниже; состояние live-книги
в этом аудите не проверялось. Общий статус: [текущий аудит](../../docs/audit-2026-11-02/README.md).

Целевой формат генератора: Minecraft 1.21.1, NeoForge, FTB Quests / Library 2101.1.36.

## Файлы и воспроизведение

- `build_campaign.py` — редактируемый источник RU/EN и генератор стабильных ID.
- `server-evidence.json` — хеши проверенных серверных JAR, модели предметов и проверенные рецепты. Наличие модели проверяет кандидат ID; успешная серверная загрузка — отдельная проверка.
- `verify_campaign.py` — проверки графа, основного маршрута, локализаций, безопасности задач и координат.
- `ValidateSnbt.java` — запускает парсер установленного FTB Library на тестовой копии.
- `install_remote.py` — установка из загруженного tar с резервной копией и сверкой модов. Не активирует книгу автоматически.
- `output/ftb-campaign/quests` — сгенерированные файлы для сервера.
- `output/ftb-campaign/CATALOG_RU_EN.md` — все названия, описания и задачи.
- `output/ftb-campaign/structural-validation.json`, `runtime-validation.json`, `parser-validation.log`, `deployment-receipt.json` — результаты проверок.

Из корня репозитория, Python 3 на PATH:

```text
python tools/ftb-campaign/build_campaign.py
python tools/ftb-campaign/verify_campaign.py
javac -d output/ftb-campaign tools/ftb-campaign/ValidateSnbt.java
```

`build_campaign.py` использует стандартную библиотеку Python. `verify_campaign.py`
дополнительно требует `output/ftb-campaign/manifest-before-redesign.json` —
сохранённый исходный manifest для сравнения стабильных ID. `output/` не хранится
в Git: на чистом клоне этот baseline нужно получить из проверенного архива
кампании; генератор не создаёт старую версию manifest. Без него полный verifier
не завершится. На машине аудита baseline был доступен; результат: 128 quests,
47 main / 81 optional, 450 translation keys, `REDESIGN_OK`.

Последняя команда только компилирует `ValidateSnbt`, Java 21. Для запуска parser
нужны путь к сгенерированному `quests` как первый аргумент и classpath с каталогом
класса, FTB Library и Minecraft runtime libraries тестового сервера. Компиляция
сама по себе не подтверждает чтение SNBT установленным FTB parser.

`preview_campaign.py` требует Pillow и `C:/Windows/Fonts/arial.ttf`; сохраняет
схемы глав Create/Survival в `output/ftb-campaign`. `presentation.py` — исходник
координат, иконок и правок текста, импортируется генератором.

`install_remote.py` — исторический Linux/SSH installer с фиксированными путями
staging от 11.10 и записью quest definitions на сервер. Это отдельная операция
установки, не локальная проверка. Для нынешней книги сначала нужен план сохранения
definitions и progress; старый installer не следует запускать как универсальное обновление.

Генератор не обращается к серверу и не меняет прогресс. JSON-синтаксис файлов является
поддерживаемым подмножеством SNBT: все десять файлов реально прочитаны FTB Library,
а затем загружены FTB Quests на сервере. Изменение текста не меняет ID;
переименование внутренних ключей меняет ID и требует отдельного решения о миграции.

## Архив: проверки установки 11.10.2026

Сведения этого раздела относятся к тому запуску. Пути резервных копий и
production-версии не перепроверялись 02.11.

Штатный перезапуск Minecraft-сервиса завершился в 15:45 по Минску.
Журнал: `Loaded 2 chapter groups, 6 chapters, 127 quests, 0 reward tables`;
загружены таблицы для двух языков. Две группы включают внутреннюю группу FTB.
Ошибок FTB Quests при загрузке нет. Существующие ошибки Railways о таблицах добычи
для отсутствующих совместимых модов не относятся к кампании и здесь не исправлялись.

Все 11 файлов `world/ftbquests` совпали по SHA-256 до установки и после перезапуска.
Старые главы удалены из активной книги по прямому указанию пользователя. Прежние
отметки не перенесены на новые ID; сохранённые данные и резервная копия позволяют
восстановить старую книгу. Конфигурация FTB Teams не изменялась.

Резервная копия: `/opt/create-server/backups/ftb-campaign-20261011T124158Z`.
В ней есть `quests`, `progress`, `retired-live-quests` и `receipt.json`.
Для отката нужно остановить только Minecraft-сервис, сохранить новую книгу,
восстановить `quests` в активный каталог с владельцем `createserver`, затем запустить
сервис. Прогресс из резервной копии следует восстанавливать только при необходимости:
безусловная замена уничтожит достижения, полученные после установки.

Команды `ftbquests reload` и `execute as ... run ftbquests reload quests` из консоли
отклонены: PermissionsHelper требует реальный игровой источник. Права игроков не
менялись. Книга активирована перезапуском, а не успешной горячей перезагрузкой.

## Границы проверки

В установке 11.10 проверены: формат установленным парсером, реальная загрузка сервера, обе таблицы
переводов, сохранность прогресса, безопасные поля задач, полный граф зависимостей,
отсутствие обязательных сайд-квестов и наложения координат. Проверена возможность
дойти по графу до диагностики шахты без выполнения боковых веток.

Реальное прохождение всех заданий solo/командой, вид книги в Minecraft при разных
масштабах GUI, сборка всех машин и практическая электрическая схема не проходились.
Структурная проверка альтернативного вступления в город не заменяет игровой тест.
Исторический startup log сообщает 127 quests; текущий generator/verifier — 128.
Это разные свидетельства: полное совпадение текущего output с live-сервером
не подтверждено и требует отдельной сверки.
Описания EE учат проверять фактические показания и пользоваться документацией
установленного EE; они не обещают непроверенную универсальную схему генератора.
