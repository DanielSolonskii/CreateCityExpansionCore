# Архитектурный контекст CCEC

Актуализировано **2026-11-04**. Текущие версии и квитанции: [CURRENT_STATE](CURRENT_STATE.md), [аудит](docs/audit-2026-11-04/README.md). Область — CCEC и вложенный `platform/`.

CCEC связывает геологию, физическую добычу, переработку Create, городское развитие и перевозки. Действующая логистика — Cargo: Router/Ticker, центры, native Create станции и расписания, реальные коробки, подтверждённая приёмка и расчёт.

## Границы

| Область | Ответственность |
| --- | --- |
| City / Projects | Членство, роли, территория, развитие, проекты и разрешения |
| Geology / Mine | Геометрия залежи, запас, EE-питание и физический выход |
| Cargo equipment | Адреса, ParcelId, маршрутизаторы, точки и доказательства движения/приёмки |
| Cargo Center | Владельцы/ACL, склады, линии, поезда, расписания, заказы и маршруты |
| Economy / CargoCommerce | Единые кошельки/казна, резервирование, выплаты и возврат |
| Map / UI | Представление серверных фактов, схема направления и понятные действия |
| Auth / platform | Серверный допуск и bridge; backend, bot и launcher имеют самостоятельные сборки |

Самостоятельные старые Freight/Railway и blast/coke/steel выведены из production до этой интеграции. Их исторические решения не являются API действующей Cargo-системы.

## Правила

1. Сервер повторно проверяет права, цену, маршрут, предмет и количество.
2. Create выполняет физическую упаковку и транспорт; CCEC не телепортирует коробки для удобного расчёта.
3. Отмена останавливает новый выпуск. Деньги за недоказанный/физический груз остаются в резерве до приёмки либо реального изъятия. Тайм-аут не доказывает потерю.
4. Промежуточная перевалка не является конечной доставкой. Платное плечо требует собственной квитанции.
5. Известный будущий формат или отказ codec не должен становиться пустым рабочим SavedData через native loader fallback.
6. Явная форма и подтверждение предшествуют покупке, отмене, удалению и восстановлению.
7. Анимация на карте показывает направление; схема не выдаётся за точные координаты коробки.
8. Gradle/headless, живой Minecraft и production deployment имеют отдельные доказательства.

## Совместимость

Целевой CCEC 1.0.2.15: Economy 16, CargoCommerce 2, Cargo shipments 2; прочие Cargo-реестры 1. Geology — codec 4 / generator 2; миграция generator 1→2 намеренно пересоздаёт залежи.

Выпуск читает описание форматов из кандидатного JAR и сравнивает его с фактическими заголовками SavedData до stop/deploy. Startup `Done` и номер версии недостаточны: [инцидент 3 ноября](docs/releases/2026-11-03-compatibility-incident.md) подтвердил это на практике.

Опциональная совместимость Sable/Simulated требует живой приёмки. Вложенный launcher snapshot имеет известные отсутствующие native модули. Offline Create simulation, fleet balancing, полный прогноз сигналов и пассажирские тарифы не заявлены реализованными.

Разработка: [README_DEV](README_DEV.md), решения: [DECISIONS](DECISIONS.md). Graph impact перед изменением и detect_changes перед коммитом обязательны по [AGENTS.md](AGENTS.md).
